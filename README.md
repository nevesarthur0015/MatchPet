## Descrição do Projeto
MatchPet é um site destinado à adoção e doação de animais de estimação de forma simplificada, com filtragem por raça e espécie, ajudando a visualização e adoção
dos pets ao trazer facilidades para quem irá adotar.

O site conta também com uma área para o registro de diferentes eventos de adoção, castração e vacinação, apoiando a formação de uma verdadeira comunidade
de cuidadores e apaixonados em animais.
